      Corriger le JSON tente de corriger automatiquement les problèmes courants avant le formatage :
      
    
        
      
      • Virgules finales (trailing commas)
        • 
      
      • Virgules manquantes entre les éléments ({"a": 1 "b": 2})
        • 
      
      • Guillemets simples au lieu de doubles
        • 
      
      • Clés sans guillemets
        • 
      
      • Commentaires // et /* */
        • 
      
      • True/False/None (style Python)
        • 
      
      • JSON entier entre guillemets ("{...}") ou sérialisé deux fois
        • 
      
      • JSON sérialisé dans un champ ("payload": "{\"a\":1}") devient un objet
        • 
      
      • Extrait copié du milieu d'un corps ("clé": valeur sans { }, ou coupé au milieu d'une chaîne)
        • 
      
      • Valeurs vides ({texte:,...} devient "")
        • 
      
      • Plusieurs objets isolés ({...} {...}) deviennent un tableau ([{...}, {...}])
