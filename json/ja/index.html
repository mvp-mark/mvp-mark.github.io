      JSON を自動修正 は、整形の前によくある問題を自動で直そうとします:
      
    
        
      
      • 末尾のカンマ（trailing commas）
        • 
      
      • 要素間のカンマ抜け（{"a": 1 "b": 2}）
        • 
      
      • ダブルクォートの代わりのシングルクォート
        • 
      
      • クォートのないキー
        • 
      
      • // と /* */ のコメント
        • 
      
      • True/False/None（Python 形式）
        • 
      
      • 全体がクォートで囲まれた JSON（"{...}"）や二重にシリアライズされた JSON
        • 
      
      • 空の値（{text:,...} は "" になります）
        • 
      
      • 複数の独立したオブジェクト（{...} {...}）は配列（[{...}, {...}]）になります
